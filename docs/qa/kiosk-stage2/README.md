# Kiosk Stage 2 browser acceptance

Run the production build and then the retained Chromium acceptance:

```bash
SKIP_REACT_SNAP=1 npm run build
PUPPETEER_EXECUTABLE_PATH=/path/to/chromium npm run test:kiosk-browser
```

The script serves the production build locally, blocks real financial APIs by
intercepting the local API origin, and uses synthetic booking/customer data. It
checks the Booking Checkout and Client 360 handoffs, credential clearing,
customer tip selection, cancellation recovery, confirmed success, minimum
touch-target sizing, and horizontal overflow at 390px, 475px, tablet, and
desktop widths. Screenshots in this directory are regenerated by the script.

This is mocked-provider browser acceptance. It is not a substitute for the
separate Stripe test-mode Checkout/webhook run when test credentials and a test
tenant are available.
